# Инструкции для генерации AI-дайджеста

## ⚡ Критические правила

### 1. Временной фильтр — ТОЛЬКО 24 часа
- Искать новости СТРОГО за последние 24 часа от момента генерации
- Дата в заголовке дайджеста = дата генерации
- Если сейчас 18 июня 2026, то новости должны быть за 17-18 июня
- НЕ включать новости старше 24 часов

### 2. Дедупликация — НЕ ПОВТОРЯТЬСЯ
- Перед генерацией прочитать файл `/root/.openclaw/workspace/memory/digest-covered.md`
- НЕ включать новости, которые уже есть в этом файле
- НЕ включать обновления без значимых изменений (только если появились новые факты)
- После генерации добавить ВСЕ освещённые новости в digest-covered.md

### 3. Ссылки на источники — ОБЯЗАТЕЛЬНО
- Каждая новость ДОЛЖНА содержать прямую ссылку на источник
- Формат: `*(Источник: [URL])*` или `*[Источник](URL)*`
- Не принимать новости без конкретного URL

### 4. Проверка наличия новостей
- Если за последние 24 часа НЕТ значимых новостей AI-индустрии:
  - Написать: "За последние 24 часа значимых новостей AI-индустрии не обнаружено."
  - НЕ создавать HTML-файл
  - НЕ отправлять сообщение в Telegram
  - Завершить задачу

## 📋 Структура дайджеста (если новости есть)

### Топ-3 новости с ПОЛНЫМ переводом

Каждое утро выбирай **3 самые важные новости** дня и делай для них **полный перевод оригинальных статей**:

1. 🏆 **Главное событие дня** — обязательно полный перевод
2. ⭐ **Вторая важная новость** — полный перевод
3. ⭐ **Третья важная новость** — полный перевод

**Что значит "полный перевод":**
- Скачай оригинальную статью по URL
- Переведи ВЕСЬ текст на русский язык
- Сохрани оригинальные картинки (вставь по прямым URL из оригинала)
- Сохрани как HTML в архив: `/root/.openclaw/workspace/news-repo/YYYY/MM/DD/slug.html`

**Формат Telegram-поста для Топ-3:**
```
**[Заголовок]**

[Первые 2-3 абзаца перевода — ключевые тезисы]

[🔗 Читать полную версию](URL_в_архиве)
```

### Остальные новости — кратко

Все остальные новости дня — краткое описание (1-3 абзаца) как раньше:
- Заголовок + описание + ссылка на источник
- Без полного перевода
- В Telegram — только краткое описание + ссылка на оригинал

   - Приоритет: критические уязвимости frontier-моделей, автономные атаки агентов, утечки данных, обходы защиты
   - Включать 1 топовую security-новость в дайджест если есть актуальная за 24 часа
