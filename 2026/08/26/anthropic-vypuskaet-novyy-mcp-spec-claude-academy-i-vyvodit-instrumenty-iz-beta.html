Anthropic выпускает новый MCP spec, Claude Academy и выводит инструменты из бета

📅 Перевод: 26.08.2026  |  🔗 Оригинал (Unrot)

Anthropic объявила на этой неделе, что несколько инструментов на платформе Claude выходят из бета-режима: инструменты computer use, browser use, Skills API и Files API теперь общедоступны для разработчиков. Анонс также включал новую открытую спецификацию для MCP — протокола, соединяющего Claude с внешними приложениями, датированную 28 июля 2026 года. Anthropic утверждает, что новая спецификация сокращает сложность запуска MCP-серверов, делая их stateless. Каталог коннекторов компании вырос до более чем 950 серверов, используемых миллионами людей ежедневно.

MCP — это инфраструктура, позволяющая Claude читать корпоративные заметки, извлекать данные из баз данных или отправлять сообщения в чат-приложения без необходимости писать пользовательский код для каждого случая. Более простая stateless-спецификация означает, что больше компаний могут безопасно интегрировать свои инструменты с Claude.

Anthropic также запустила Claude Academy — бесплатный образовательный хаб с курсами и бейджами, нацеленный на обучение людей эффективному использованию AI. По сравнению с OpenAI и Google, которые сделали ставку на потребительские приложения, толчок Anthropic в сторону инфраструктуры для разработчиков и образовательного контента соответствует её давней стратегии — быть AI-компанией, на которой строят бизнес.
