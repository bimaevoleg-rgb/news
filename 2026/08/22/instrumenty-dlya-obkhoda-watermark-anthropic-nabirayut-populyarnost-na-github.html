Инструменты для обхода watermark Anthropic набирают популярность на GitHub

📅 Перевод: 22.08.2026  |  🔗 Оригинал (Simon Willison's Blog)

GitHub-репозитории с инструментами для удаления watermark Anthropic набрали более 14,000 звёзд, вызывая бурные дебаты о безопасности и ответственности в сфере AI. Watermark Anthropic встроен в модели Claude для идентификации AI-генерированного контента, но разработчики создали эффективные методы его обхода.

Этот инцидент подчёркивает растущую гонку между разработчиками защитных механизмов и теми, кто их обходит. Эксперты отмечают, что технические решения для идентификации AI-контента могут быть недостаточными без сопутствующих регуляторных мер и развития медиаграмотности.
