Microsoft интегрирует модели xAI в Copilot по всему офисному стеку

📅 Перевод: 13.09.2026  |  🔗 Оригинал (AI Tools Recap)

Microsoft добавила модели xAI в Copilot в приложениях Word, Excel, PowerPoint, GitHub Copilot и рабочих инструментах — анонс сделал Сатья Наделла 12 сентября. Функция доступна для клиентов Frontier при включении администратором, и недоступна в ЕС, ЕАСТ и Великобритании на этапе предварительного просмотра.

Microsoft является крупнейшим инвестором OpenAI и теперь поставляет модели Anthropic и xAI внутри того же интерфейса. Это превращает Copilot в маркетплейс моделей, а не в продукт с моделью внутри.

Расширение линейки моделей в Copilot отражает стратегию Microsoft по предоставлению предприятиям выбора AI-моделей в рамках единой платформы, позволяя организациям использовать разные модели для разных задач без необходимости управлять несколькими отдельными интеграциями.
