Perplexity запускает локального AI-агента Portable Computer на Windows для GPU NVIDIA с 24GB+ VRAM

📅 Перевод: 16.09.2026  |  🔗 Оригинал (NVIDIA Blog)

По мере того как локальные модели становятся более способными, AI-агенты могут выполнять больше работы непосредственно на ПК, сохраняя конфиденциальную информацию на устройстве.

Portable Computer — это локальная версия агента Perplexity Computer, который планирует и выполняет многоэтапные задачи. Ускоряемый GPU NVIDIA, он использует локальные модели для анализа данных, объединения информации между файлами и обработки регулярной работы. Конфиденциальная информация остаётся на устройстве, а локально выполненная работа не расходует кредиты Perplexity Computer. Пользователи также могут оркестрировать работу с облачными моделями для более продвинутых исследований и рассуждений.

Сегодня Perplexity добавляет Portable Computer в приложение Perplexity для Windows на совместимых ПК с NVIDIA GeForce RTX и рабочих станциях NVIDIA RTX PRO, принося мощный агентный AI большему числу пользователей Windows. Релиз опирается на существующую поддержку систем NVIDIA DGX Spark и RTX-ПК под управлением Linux.

Perplexity объединяет локальный и облачный AI в одном приложении, позволяя пользователям работать с конфиденциальными файлами на своих ПК и использовать встроенные инструменты Computer, такие как встроенный браузер и фирменная песочница SPACE.

Для задач, требующих более продвинутых рассуждений, Portable Computer может определить, когда задача нуждается в облачной поддержке, запрашивая у пользователя разрешение перед отправкой информации за пределы устройства.

Приложение упрощает настройку с локальной моделью, такой как Qwen 3.8 27B, которая пост-тренирована для работы с Perplexity Computer и оптимизирована для GPU NVIDIA RTX. Пользователи могут приступить к работе без необходимости исследовать модели или настраивать сложный программный стек, обычно требуемый для запуска локального AI.

Коннекторы для Microsoft Outlook, OneDrive, Word, Google Drive, Gmail, Slack и GitHub расширяют этот опыт на файлы и приложения, которые уже являются частью повседневных рабочих процессов пользователей. Например, агент может помочь с:

Инженерией: Просмотр открытых pull request в подключённом проекте GitHub, организация их по статусу и определение следующих шагов. Computer также может выявлять устаревшую документацию и отправлять предложенные обновления на ревью.

Финансами: Направьте Computer на два года брокерских выписок, консолидированных форм 1099 и налоговых деклараций, и он проследит повторяющиеся вложения, создающие наибольшие избежные комиссии и налоговые издержки, с указанием каждой цифры до конкретного файла и страницы — всё это без того, чтобы какой-либо документ попал в чат-бот.

Стартапами: Спросите Computer, почему активация застопорилась, и агент локально проанализирует экспорт воронки, чтобы найти, где новые регистрации отваливаются между установкой и первым завершённым заданием, а затем отправит главные инсайты прямо в Slack-канал команды.

Portable Computer доступен для GPU NVIDIA GeForce RTX и RTX PRO с 24 ГБ и более видеопамяти. Поддержка NVIDIA DGX Station ожидается в ближайшее время.

В дополнение: Z.ai GLM 5.3 Flash обеспечивает впечатляющую производительность и визуальный интеллект по низкой цене, оптимизирован для DGX Station и двойных систем DGX Spark. DeepSeek-v4.1 Flash значительно снижает требования к памяти key-value кэша и эксплуатационные расходы для сложных AI-агентных нагрузок. Qwen выпустила Qwen3.8-Flash-Next — открытовесную мультимодальную MoE-модель — и ранний превью Qwen4, которая может работать локально на одном DGX Spark с NVFP4. GLM 5.3 — флагманская модель Z.ai на 744 миллиарда параметров, настроенная для агентных сессий, длящихся часами на DGX Station и кластере из четырёх DGX Spark.
