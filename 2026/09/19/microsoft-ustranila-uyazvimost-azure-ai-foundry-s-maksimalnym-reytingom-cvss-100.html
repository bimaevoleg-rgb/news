Microsoft устранила уязвимость Azure AI Foundry с максимальным рейтингом CVSS 10.0

📅 Перевод: 19.09.2026  |  🔗 Оригинал (The Hacker News)

Microsoft выпустила исправления для уязвимости максимальной степени серьёзности в Azure AI Foundry, которая могла быть использована для повышения привилегий. Действий со стороны клиентов не требуется.

Уязвимость, отслеживаемая как CVE-2026-85889, имеет рейтинг CVSS 10.0 — максимально возможный.

«Отсутствие аутентификации для критической функции в Azure AI Foundry позволяет неавторизованному атакующему повысить привилегии по сети», — заявила Microsoft в бюллетене в четверг.

Azure AI Foundry, также называемая Microsoft Foundry, — это корпоративная платформа, предназначенная для создания, развёртывания и управления приложениями и агентами генеративного искусственного интеллекта.

Производитель Windows отдал должное исследователю безопасности Реми Маро за обнаружение и ответственное раскрытие уязвимости. Доказательств того, что проблема была эксплуатирована в реальной среде, нет.

За последние дни Microsoft также устранила ряд других критических уязвимостей:

— CVE-2026-85885 (рейтинг CVSS: 9.9) — уязвимость внедрения команд в Microsoft 365 Copilot, которая могла позволить авторизованному атакующему повысить привилегии по сети;

— CVE-2026-85878 (рейтинг CVSS: 9.9) — неправильная авторизация в Azure Database for PostgreSQL, которая могла позволить авторизованному атакующему повысить привилегии по сети;

— CVE-2026-87701 (рейтинг CVSS: 9.6) — неправильная нейтрализация в Azure Cosmos DB, которая могла позволить авторизованному атакующему повысить привилегии по сети.

Как это обычно бывает с облачными CVE, Microsoft заявила, что уязвимости уже полностью устранены и не требуют никаких действий со стороны пользователей.

Отдельно Microsoft выпустила обновления для двух других уязвимостей, одна из которых была раскрыта в прошлом месяце:

— CVE-2026-62721 (рейтинг CVSS: 7.8) — недостаточная детализация контроля доступа в Windows User-Mode Power Service (UMPS), которая могла позволить авторизованному атакующему локально повысить привилегии и получить права SYSTEM;

— CVE-2026-85921 (рейтинг CVSS: 8.2) — уязвимость двойного освобождения в Windows Secure Kernel Mode, которая могла позволить авторизованному атакующему локально повысить привилегии и получить права Virtual Trust Level 1 (VTL1).

Обе уязвимости были устранены в рамках внепланового обновления для Windows 11 версии 26H1 — накопительного обновления KB5129194 (сборка 28000.2956) для систем на базе arm64 и x64.

Это раскрытие происходит на фоне рекордного выпуска исправлений Patch Tuesday на прошлой неделе, в котором было устранено 974 уязвимости по всему портфелю продуктов компании. Две из них, затрагивающие Windows Advanced Local Procedure Call (ALPC) и стек обновлений Windows, уже находятся под активной эксплуатацией.

По сообщениям Proofpoint и Volexity, уязвимость ALPC была объединена в цепочку с двумя уязвимостями Google Chrome для создания эксплойт-кита под названием BlueMoon, который был оружизирован множеством группировок, связанных со шпионажем, для доставки вредоносных полезных нагрузок.
