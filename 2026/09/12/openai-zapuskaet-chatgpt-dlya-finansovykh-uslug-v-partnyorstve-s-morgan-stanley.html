ENTERPRISE

OpenAI запускает ChatGPT для финансовых услуг в партнёрстве с Morgan Stanley и Evercore

📅 Перевод: 12.09.2026  |  🔗 Оригинал (OpenAI Blog)

OpenAI представляет ChatGPT для финансовых услуг — специализированную версию своего ИИ-ассистента, разработанную для банков, инвестиционных фирм и страховых компаний. Продукт запущен в партнёрстве с Morgan Stanley и Evercore, которые уже внедрили решение в свои рабочие процессы.

Новая платформа предлагает соответствие нормативным требованиям финансовой отрасли, включая аудит всех взаимодействий, контроль данных и интеграцию с существующими системами соответствия. Модель обучена на финансовых данных и может помогать в анализе рынка, составлении отчётов и взаимодействии с клиентами.

«ChatGPT для финансовых услуг представляет собой значительный шаг вперёд в корпоративном применении ИИ», — заявил глава отдела корпоративных решений OpenAI Лиам Федус. «Мы работали в тесном сотрудничестве с ведущими финансовыми институтами, чтобы обеспечить соответствие самым строгим требованиям отрасли».

Morgan Stanley использует платформу для анализа рыночных трендов и подготовки инвестиционных рекомендаций, в то время как Evercore применяет её для моделирования сделок и финансового моделирования. Платформа включает функции для анализа документов SEC, отслеживания рыночных движений в реальном времени и генерации настраиваемых финансовых отчётов.

Решение доступно через API и может быть интегрировано в существующие банковские системы. OpenAI заявляет, что все данные клиентов обрабатываются в изолированной среде и не используются для обучения моделей. Стоимость лицензирования начинается от 50 000 долларов в год для малых фирм и достигает нескольких миллионов для крупных банков.
