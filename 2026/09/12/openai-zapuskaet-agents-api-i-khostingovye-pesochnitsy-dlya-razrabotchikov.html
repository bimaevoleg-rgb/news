OpenAI запускает Agents API и хостинговые песочницы для разработчиков

📅 Перевод: 12.09.2026  |  🔗 Оригинал (OpenAI Blog)

По мере масштабирования Codex и ChatGPT for Work для миллионов пользователей по всему миру мы узнали, что необходимо для эффективной работы долгосрочных агентов. Полезные агенты нуждаются в мощной системе управления контекстом, эффективном использовании инструментов и координации подагентов. Они также нуждаются в инфраструктуре, которая обеспечивает надёжную работу в течение нескольких дней, с возможностью работы с файлами, запуска кода и сохранения промежуточных результатов.

Сегодня мы представляем Agents API в публичной бета-версии, предоставляя разработчикам ту же систему и инфраструктуру, которая обеспечивает работу Codex, через простой и гибкий API.

С помощью Agents API вы можете создать готового к работе агента одним вызовом API, указав задачу, модель, инструменты и окружение. OpenAI размещает и поддерживает систему управления агентами. Вы выбираете вычислительное окружение агента: в управляемой OpenAI песочнице, на собственной инфраструктуре или с одним из партнёров по песочницам.

Мы сотрудничаем с экосистемными провайдерами, включая Blaxel, Cloudflare, Daytona, DigitalOcean, E2B, Modal, Oracle, Runloop и Vercel, чтобы предоставить интеграции первого класса для различных нужд: полностью управляемые окружения или развёртывания в вашем VPC, специфические механизмы хранения файлов и секретов, различные конфигурации CPU, GPU и памяти.

Для разработчиков, которые хотят быстро начать работу и эффективно масштабироваться, мы также представляем хостинговые песочницы OpenAI. Это использует ту же инфраструктуру песочниц, которая обеспечивает работу Codex и ChatGPT. OpenAI предоставляет и управляет песочницей, предоставляя вашему агенту безопасное и производительное окружение для запуска кода, работы с файлами и создания артефактов.

Agents API предоставляет версионированный доступ к возможностям с каждым запуском модели. Мы поддерживаем и постоянно совершенствуем систему управления агентами наряду с нашими моделями, помогая вашим агентам получать лучшую производительность от каждого обновления.

Для поддержки моделей, работающих часами, мы создали управление контекстом, которое помогает агентам переносить релевантную информацию через более длинные сессии. Agents API автоматически компактизирует ранний контекст по мере приближения сессии к лимиту контекста, сохраняя информацию, необходимую агенту для продолжения.

Agents API помогает агентам находить правильные инструменты и использовать их эффективно. Поиск инструментов загружает релевантные определения инструментов по мере необходимости, помогая сократить использование токенов и стоимость, сохраняя кэш модели. API поддерживает MCP, пользовательские функции и встроенные инструменты, такие как веб-поиск.

С поддержкой мультиагентности Agents API может разбивать сложные задачи на независимые части и делегировать их подагентам, работающим параллельно. Каждый подагент поддерживает собственный контекст, помогая ему сосредоточиться на своей задаче, в то время как основной агент координирует их работу и объединяет результаты.

Agents API работает на основе открытого исходного кода Codex harness, предоставляя разработчикам видимость основной логики, которая координирует вызовы моделей, инструменты и контекст. С Agents API OpenAI эксплуатирует и поддерживает эту систему, в то время как разработчики могут изучать и учиться на её публичной кодовой базе.

Agents API доступен сегодня в публичной бета-версии для всех разработчиков. Нет дополнительных сборов за использование Agents API — вы просто платите за токены и инструменты, которые используют ваши агенты.
